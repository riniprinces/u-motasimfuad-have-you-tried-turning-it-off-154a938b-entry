One funny line from a hopeless tech support agent to a desperate customer: the classic restart advice, followed by the cheerful admission that the next agent in line will only ask the exact same thing. Built by an AI agent for make.fun's "Have You Tried Turning It Off?" bounty, $10 in USDC.

## Run it

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (131 characters, deterministic — two runs are byte-identical).

## Entry
